# Prepare two portraits

For the [Zombie Trend Video creator](https://zombietrendvideo.com/), prepare one separate image for each consenting adult.

| Check | What to use |
| --- | --- |
| Role | First image: human survivor. Second image: zombie companion. |
| File | JPG, PNG or WebP; up to 6 MB each. |
| Dimensions | At least 256 pixels on both sides. |
| Face | One clear, sufficiently large face per image. |
| Light | Even light, without strong shadows across the face. |
| Visibility | Eyes, nose and mouth visible; avoid masks, sunglasses and heavy filters. |

No zombie makeup or matching background is needed. If your phone saves HEIC, export a JPG or PNG; renaming the extension does not convert the image.

Before uploading, confirm that you have permission to process both photos and read the [photo requirements](https://zombietrendvideo.com/photo-requirements) and [privacy information](https://zombietrendvideo.com/privacy). Do not upload personal portraits to this GitHub repository.
